## 📖 Описание

**Questions_Generator_TGBot** — это Telegram-бот, предоставляющий удобный интерфейс для генерации экзаменационных билетов с использованием предварительно обученных LoRA-адаптеров на основе модели Mistral-7B. Бот позволяет пользователям создавать качественные экзаменационные вопросы по различным предметным областям прямо в Telegram.

### 🎯 Назначение

Бот предназначен для преподавателей и студентов, которым необходимо быстро генерировать экзаменационные билеты по специализированным дисциплинам без необходимости технической настройки моделей машинного обучения.

### 📚 Поддерживаемые предметные области

- **Криптография** — алгоритмы шифрования, цифровые подписи, протоколы безопасности
- **Компьютерные сети** — протоколы TCP/IP, маршрутизация, сетевая безопасность
- **Алгоритмы и структуры данных** — сортировки, графы, деревья, динамическое программирование

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Aralary/Questions_Generator_TGBot.git
cd Questions_Generator_TGBot
```

### 2. Создание виртуального окружения

**Linux / macOS:**
```bash
python3.12 -m venv venv
source venv/bin/activate
```

**Windows:**
```powershell
python.exe -m venv venv
.\venv\Scripts\activate
```

### 3. Установка зависимостей

**С поддержкой GPU (CUDA 12.4+):**
```bash
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu124
```

**Только CPU:**
```bash
pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cpu
```

### 4. Настройка конфигурации

Откройте файл `config.py` и добавьте токен вашего Telegram-бота:

```python
# config.py
BOT_TOKEN = "YOUR_TELEGRAM_BOT_TOKEN_HERE"
```

> 💡 **Как получить токен бота:**
> 1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
> 2. Отправьте команду `/newbot`
> 3. Следуйте инструкциям для создания бота
> 4. Скопируйте полученный токен в `config.py`

### 5. Подготовка адаптеров

Разместите обученные LoRA-адаптеры в следующей структуре:

```
models/
└── adapters/
    ├── cryptography/
    │   ├── adapter_config.json
    │   └── adapter_model.safetensors
    ├── networks/
    │   ├── adapter_config.json
    │   └── adapter_model.safetensors
    └── algorithms/
        ├── adapter_config.json
        └── adapter_model.safetensors
```

> 📦 **Где взять адаптеры:**
> 
> Адаптеры создаются с помощью проекта [Questions_Generator_Core](https://github.com/Aralary/Questions_Generator_Core). После обучения скопируйте папки из `data/adapters/` в `models/adapters/` этого проекта.

### 6. Запуск бота

```bash
python bot.py
```

## 📘 Использование бота

### Команды бота

- `/start` — начало работы с ботом, приветственное сообщение

### Процесс генерации билета

1. **Запустите бота** — отправьте команду `/start`
2. **Выберите домен** — криптография, сети или алгоритмы
3. **Укажите количество вопросов** — от 2 до 5 вопросов в билете
4. **Укажите количество билетов** — 1/3/5/10/15/20/25/30
5. **Выберите формат ответа** - сообщение, ***.txt*** файл или ***.pdf***
5. **Получите результат** — бот сгенерирует и отправит билет

### Проблема: Медленная генерация

**Причина:** Работа на CPU или недостаточно мощный GPU

**Решение:**
- Используйте GPU с CUDA
- Уменьшите `MAX_NEW_TOKENS` в `config.py`
- Рассмотрите использование более быстрого сервера
